## Reproducible acquisition and locators

Script: scripts/yerushalmi_search.py (Python stdlib). It uses actual `json_url` entries rather than inferred bucket paths, selects title prefix `Jerusalem Talmud `, Hebrew language, merged version and direct Talmud/Yerushalmi categories. SHA-256 of the raw books inventory and each retrieved work are recorded. Index schemas fetched through `/api/v2/raw/index/<title>` validate a depth-three JaggedArrayNode with Perek/Halakhah/Integer addresses. Every candidate locator is generated from its actual array indices (chapter:halakha:segment). Unexpected schema/depth causes an error instead of an invented locator. This avoids the legacy API's work/chapter request silently returning only the first halakha.

All string leaves in each downloaded merged export were traversed. That is a complete discovery pass of this accessible inventory snapshot, not a claim that every historical Yerushalmi witness or edition was searched. Empty strings are counted as returned segments; nonempty counts are provided per work. Alternative versions, manuscript variants and non-indexed material remain outside this pass.

## Queries and status

For matching, decode HTML entities, remove HTML tags, strip Hebrew cantillation/vowel/punctuation code points U+0591–U+05C7, then tokenize Hebrew letters. Original extracted candidate text retains pointing. Match:

- סוס substring, covering forms such as סוסים, סוסין, סוסיא, סוסייא, סוסתא and prefixes/suffixes; explicit morphological-form subclass adds precision without removing broader candidates.
- Prefix-bounded פרש / פרשים / פרשין / פרשיא / פרשייא / פרשא, retaining lexical ambiguities.
- Substrings מרכב, אורוו, אוריו, אספסט, היפוס for indirect/loanword/stable candidates.

False positives remain intentionally queued: examples include סוסרטיי and קסוסטבן; מפרשין is semantically ambiguous. Machine matching does not mark primary reading, quote verification, contextual interpretation or independent review as true. Each candidate explicitly has all manual-check flags false. YER-001 records remain the separate authority for previously verified locations.

Sefaria Export README and LICENSE.md were read: each version has its own license. Merged exports omit a license field. Supplemental API metadata for each work records constituent versions' license values. Guggenheimer is reported CC-BY. Niddah merges Guggenheimer with Mechon-Mamre; latter is reported unknown, and per-segment provenance has not been resolved. Manifest retains that limitation rather than assigning a blanket license.
