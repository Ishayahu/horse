## Практический порядок с источником ПОСЛЕ каждого этапа

Это **синтез** разных традиций, а не единый документированный мингаг. Применение дополнительных предосторожностей (особенно полотенца после миквы/туалета) не следует считать обязательным.

**Этап 1 — пробуждение.** Произнести «Моде ани», рядом с кроватью омыть руки трижды **попеременно** (П–Л, П–Л, П–Л). По хабадскому порядку первое омовение без благословения.

**Источник:** [Бейт Хабад, утреннее омовение](https://he.chabad.org/library/article_cdo/aid/1448901); [Махон галаха Хабад, рав Шломо Гальперн](https://machon-halacha.co.il/נטילת-ידיים-לאחר-השינה/).

**Этап 2 — туалет после пробуждения.** После туалета можно омыть руки из сосуда трижды попеременно. Но отдельное омовение *плюс* второе утреннее непосредственно подряд — **не самостоятельный документированный хумра**; не объявлять 18 обливаний требованием.

**Источник:** [Рав Ицхак Гринблат, после туалета](https://www.yeshiva.org.il/ask/81881); [Шульхан арух а-Рав, ОХ 6:1](https://www.chabad.org/library/article_cdo/aid/3268368/jewish/Shulchan-Aruch-Chapter-6-Laws-Relating-to-Blessings-Asher-Yatzar-Elokai-Neshamah-their-Meanings.htm).

**Этап 3 — второе утреннее омовение.** После одежды, предпочтительно после туалета: второе омовение через ткань/полотенце при держании сосуда; благословение «Аль нетилат ядаим» по принятому мингагу. **Попеременное омовение при пробуждении и три подряд на каждой руке перед хлебом — не одна и та же процедура; не переносить порядок перед хлебом автоматически на вторую утреннюю нетилу.**

**Источник:** [Махон галаха Хабад](https://machon-halacha.co.il/נטילת-ידיים-לאחר-השינה/); [Хабад, ткань при второй нетиле](https://www.chabad.org.il/Questions/PrintQuestion.asp?ArticleID=7643&CategoryID=68); [«Лекет йошер» I, ОХ 7:2 — исторический случай](https://ashoova.co.il/ask/לקט-יושר-חלק-א-אורח-חיים-ז׳/amp/).

**Этап 4 — туалет в течение дня.** Вымыть руки, затем по дополнительной практике омыть их из сосуда трижды попеременно; вытереть и произнести «Ашер яцар», если были отправлены нужды. Наложение полотенца на сосуд **не найдено** как отдельный подтверждённый мингаг для обычного туалета.

**Источник:** [Рав Ицхак Гринблат, подробный респонс](https://www.yeshiva.org.il/ask/81881); [«Махзик браха» через цитату на сайте рава Мордехая Элиягу](https://harav.org/books/harav_harashi_1_1/).

**Этап 5 — после миквы.** Можно омыть руки единожды под краном. Трижды попеременно через полотенце — **предполагаемое добровольное дополнение**, не проверенный исторический обычай, не галахическая обязанность.

**Источник:** [Рав Даниэль Кирш, различает микву и кладбище](https://www.yeshiva.org.il/ask/139796).

**Этап 6 — перед хлебом.** По хабадской практике сосуд через полотенце, три последовательных обливания правой, затем три левой; далее потирание рук, благословение и вытирание по описанному порядку.

**Источник:** [Хабад — подробный порядок нетилы перед хлебом](https://www.chabad.org.il/Questions/PrintQuestion.asp?ArticleID=508&CategoryID=68); [«Сефер ха-минагим», PDF](https://media.chabad.info/chabadinfoheb/wp-content/uploads/2021/11/12-11-2021-02-13-00-%D7%A1%D7%A4%D7%A8-%D7%94%D7%9E%D7%A0%D7%94%D7%92%D7%99%D7%9D-%D7%A0%D7%98%D7%B4%D7%99-%D7%91%D7%A8%D7%9B%D7%94%D7%B4%D7%96-%D7%91%D7%A8%D7%94%D7%B4%D7%A0-%D7%95%D7%AA%D7%A4%D7%99%D7%9C%D7%AA-%D7%94%D7%93%D7%A8%D7%9A.pdf#page=4).
