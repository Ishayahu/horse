# Промежуточные материалы исследований

Все материалы конкретной темы находятся в `research/<codename>/`. Здесь только общий навигационный указатель.

- [`horse`](horse/README.md) — Танах, Бавли, Иерушалми, мидраши, комментарии, каббала, датировки и сравнения; дополнительная работа находится в `horse/supplement/`.
- [`yirat-shamayim`](yirat-shamayim/README.md) — отдельная тема страха Небес со своим состоянием и источниками.

Кодовое имя совпадает с именем каталога [итоговых отчётов](../reports/README.md): `reports/<codename>/`. [Общая методология](../docs/methodology.md) · [Очередь и запуск](../RESEARCH-RUNNER.md).
