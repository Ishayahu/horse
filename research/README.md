# Промежуточные материалы исследований

Все материалы конкретной темы находятся в `research/<codename>/`. Здесь только общий навигационный указатель.

- [`horse`](horse/README.md) — Танах, Бавли, Иерушалми, мидраши, комментарии, каббала, датировки и сравнения; дополнительная работа находится в `horse/supplement/`.
- [`yirat-shamayim`](yirat-shamayim/README.md) — отдельная тема страха Небес со своим состоянием и источниками.

- [`rosenblum-parasha`](rosenblum-parasha/README.md) — открытые вопросы по урокам рава Баруха Розенблюма (Тора до Синая; мамзеры и לב טהור); зарегистрировано в конце автоматической очереди (позиции 5–6, после YIRAT).

- [`ritual-handwashing`](ritual-handwashing/research-assignment.md) — исторические сведения об омовении рук с тканью, троекратном омовении после туалета, микве; [ссылки](ritual-handwashing/sources.md). ON-DEMAND.

- [`morning-blessings`](morning-blessings/README.md) — утренние благословения: обычаи и источники, ON-DEMAND.

- [`pre-shacharit`](pre-shacharit/README.md) — документированные устрожения между утренними благословениями и шахаритом. ON-DEMAND.

Кодовое имя совпадает с именем каталога [итоговых отчётов](../reports/README.md): `reports/<codename>/`. [Общая методология](../docs/methodology.md) · [Очередь и запуск](../RESEARCH-RUNNER.md).
