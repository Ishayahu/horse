# Устрожения при омовении рук — результаты WASH-001

**Дата:** 2026-10-29 · **Статус:** предварительно проверенная подборка; НЕ исчерпывающий поиск.

| Предмет | Доказательство | Ограничение |
|---|---|---|
| Утром сосуд через ткань | [«Лекет йошер» I, ОХ 7:2](../../research/ritual-handwashing/sources.md) — утренняя нетила р. Исраэля Иссерлейна **после выхода из туалета**, правую руку защищает тканью при взятии сосуда для левой | Три обливания *каждой рукой подряд*; не доказан обычай после каждого туалета |
| Хабад: после пробуждения | [Махон галаха Хабад](https://machon-halacha.co.il/נטילת-ידיים-לאחר-השינה/) и [AskTheRav](https://asktherav.com/40310-hebrew-regarding-washing-in-the-morning/) — вторая утренняя нетила с полотенцем | Не автоматически первое омовение возле кровати |
| После туалета — троекратность | [Хида в цитате у р. Мордехая Элиягу](https://harav.org/books/harav_harashi_1_1/), [«Архот маран» через אתר ישיבה](https://www.yeshiva.org.il/ask/134141/) | Хида не указывает чередования; р. Овадья Йосеф по сыну чередовал, но из крана |
| После туалета — сосуд | [Хазон Иш и Стайплер](https://www.hidabroot.org/question/260806), [Хафец Хаим, Баба Сали, р. Мордехай Шараби](https://www.hidabroot.org/article/122590) | Вторичные данные, не полотенце |
| После туалета — полотенце | [Дискуссия рав Шабтая Йоны Фридмана](https://old2.ih.chabad.info/images/notimage/85710_he_1.pdf#page=104) | Только предложенный вариант совместного омовения после туалета и перед едой, не реальный зафиксированный мингаг |
| После миквы — полотенце | [Шו״ת גם אני אודך](https://www.toratemetfreeware.com/online/f_01930.html): хасид из Бельза избегал касаться полотенца голой рукой | Это полотенце *для тела*, не сосуд |
