## Практическая реконструкция при максимальном сочетании разных обычаев (не единый засвидетельствованный мингаг)

1. **После пробуждения:** первая нетила у кровати, из сосуда, три попеременных обливания каждой руки (П–Л ×3). По рассмотренному обычаю Хабада благословение откладывается до второго утреннего омовения. [Махон галаха Хабад](https://machon-halacha.co.il/נטילת-ידיים-לאחר-השינה/).
2. **После утреннего туалета:** если буквально воспроизводить *также* устрожение после каждого туалета — отдельные три попеременных обливания каждой руки (П–Л ×3). Затем второе утреннее омовение по порядку нетилы перед хлебом: три подряд на правую руку, три подряд на левую, взяв сосуд через полотенце; благословения — согласно своему мингагу, не удваивать. **Отдельная нетила после утреннего туалета + вторая утренняя нетила — искусственное сложение; источники не предписывают две независимые процедуры подряд.** [Нетила после туалета](https://www.yeshiva.org.il/ask/81881), [хабадский порядок перед едой](https://www.chabad.org.il/Questions/PrintQuestion.asp?ArticleID=508&CategoryID=68).
3. **После туалета днём:** санитарное мытьё при необходимости; из сосуда трижды попеременно на каждую руку; полотенце на сосуде — лишь добровольное распространение чужого обычая, без прямого найденного свидетельства. «Ашер яцар» — после справления нужды, а не просто после посещения помещения. [Ответ о трёх попеременных обливаниях](https://www.yeshiva.org.il/ask/81881).
4. **После миквы:** одно омовение рук водой, можно без сосуда; благословения на нетилу нет. Трижды попеременно и через полотенце — гипотетическое усиление, **не найденный мингаг**. [Ответ об омовении после миквы](https://www.yeshiva.org.il/ask/139796).
5. **Перед хлебной трапезой:** три последовательных обливания правой, затем три левой с удержанием сосуда через полотенце, как описано для Хабада; благословение по порядку нетилы перед едой. [Подробный порядок](https://www.chabad.org.il/Questions/PrintQuestion.asp?ArticleID=508&CategoryID=68).

**Нельзя объявлять обязательным** смешанный «наиболее строгий» алгоритм или утверждать, будто его в целом соблюдал конкретный раввин. Особенно нельзя выводить необходимость двух дополнительных троекратных циклов из сосуществования разных практик. Часть вариантов относится к разным галахическим целям (руах раа, очищение рук, нетила перед едой). Принятие новой постоянной личной практики обсуждать с раввином; при выборе ограничения использовать «בלי נדר».
