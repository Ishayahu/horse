# Промежуточные материалы исследований

**Норма:** для каждого самостоятельного исследования существует ровно один постоянный `codename`, совпадающий с названием папок здесь (`research/<codename>/`) и в [отчётах](../reports/) (`reports/<codename>/`). Здесь хранятся все рабочие материалы, исходные тексты и выгрузки, кандидаты, состояния, реестры, скрипты, проверки и подзадачи. Внешние публикации — в `reports/<codename>/`.

- **[`horse`](horse/README.md)** — основная тема коней и её дополнение; исходная литература и промежуточные материалы ещё частично находятся в исторических папках, см. карту миграции внутри.
- **[`yirat-shamayim`](yirat-shamayim/README.md)** — самостоятельное исследование יראת שמים; рабочие файлы уже в своём каталоге.

**Временное наследие:** `research/tanakh/`, `bavli/`, `yerushalmi/`, `midrash/`, `commentaries/`, `later-literature/`, `kabbalah/`, `perek-shira/`, `comparative/`, `egypt/`, `provenance/`, `verification/`, `horse-supplement/` — промежуточные результаты только исследования `horse`; их ещё предстоит атомарно перенести в `research/horse/` с проверкой путей. Новые самостоятельные темы не должны создавать такие одноуровневые каталоги.
